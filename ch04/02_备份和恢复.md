### 数据目录

所有与特定 Geth 实例相关的数据都会写入数据目录中。默认数据目录位置因平台而异:
- Mac: ~/Library/Ethereum
- Linux: ~/.ethereum
- Windows: %LOCALAPPDATA%\Ethereum

账户存储在密钥库子目录中。此目录的内容应该可以在节点、平台和客户端实现之间传输。

要配置数据目录的位置，可以指定 `--datadir` 参数。多个网络可能存在多个数据目录（例如，以太坊主网和 Goerli 测试网分别对应一个目录）。每个网络都有用于存储其区块链数据和密钥库的子目录。

安全备份密钥库中的文件非常重要。这些文件使用账户密码加密。账户密码也需要安全备份。没有密码就无法解密密钥！

### 清理

可以使用以下方法删除 Geth 的区块链和状态数据库:
```s
  geth removedb
```

这对于删除旧链并同步到新链非常有用。它仅影响可在同步时重新创建的数据目录，而不会影响密钥库。具体来说，传递不带参数的 `removedb` 命令会删除完整节点状态数据库、旧数据库和轻节点数据库（尽管轻节点目前在权益证明以太坊中无法使用）。

### 区块链导入/导出

使用以下二进制格式导出区块链:
```s
  geth export <filename>
```

或者，如果您想备份链中一段时间​​内的某些部分，可以指定第一个区块和最后一个区块。例如，要备份第一个 epoch:
```s
  geth export <filename> 0 29999
```
请注意，备份部分链时，文件将被附加而不是截断。

使用以下命令导入二进制格式的区块链导出:
```s
  geth import <filename>
```
