
除了状态变量，智能合约还有另外一种永久记录数据的方式，这种方式是合约事件(event)，它会以日志的形式在链上永久保存，并且它的存储成本要比状态变量低。

事件的定义方式如下:
```js
event event_name(paramlists...);
```

事件只需要声明，对于个别字段也可以使用`indexed`关键字来修饰，代表该字段是索引，可以在日志中更快速地查找。触发事件需要使用`emit`关键字，用法如下:
```js
emit event_name(realparamlists...);
```

当事件被触发时，监听该合约的客户端会收到对应的消息，消息内容包含事件名称及相关参数。因此，事件除了存储数据外，也可以帮助开发者像查看日志语言那样检查合约执行过程中的数据变化。
