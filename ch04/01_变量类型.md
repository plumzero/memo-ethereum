
### 基础类型

| 数据类型 | 说明 |
|:--------|:----|
| string  | 字符序列，使用 UTF-8 编码 |
| bool    | 布尔类型 |
| int     | 有符号整数，等价于 int256 |
| uint    | 无符号整数，不能表示负数，等价于 uint256 |
| address | 地址，用来表示账户或合约，可以用来转账 |
| bytes   | 字节数组 |
| int8~int256 | 按字节增长的有符号整数类型 |
| uint8~uint256 | 按字节增长的无符号整数类型 |
| bytes1~bytes32 | 按字节增长的定长字节类型 |

其他注意:
- 一个 int8、uint8、bytes1 都占用 1 个字节，这 3 种类型每增加 1 个字节就会产生一个新的数据类型，最大是 32 个字节，对应的是 int256、uint256、bytes32。
- Solidity 语言并未提供浮点数类型，若想要使用浮点数，可以通过两个整型数来表示，前一个表达数据值，第二个表达数据精度(小数点的位数)。例如，数值为1234，精度为2，那么这个实际的数值是12.34。

### 自定义复合类型

- 定长数组: 具有 length 属性。
- 动态数组: 具有 length 属性，可以使用 push 函数追加一个元素，使用 pop 函数删除最后一个元素。
- mapping: 基于 key-value 存储的容器，语法为`mapping(T1 => T2) modifiers mapname;`。
- struct: 自定义结构体，用于描述一个事物的多个特性。struct 可以作为新的类型，可以作为数组和mapping的元素使用。
