
### 检查账户余额

这是一个发送到本地端口 8545 的 HTTP POST 请求。`-H`标志用于标头信息，它在此处用于定义传入有效负载的格式，即 JSON。`--data`标志定义有效负载的内容，该负载是一个 JSON 对象。该 JSON 对象包含四个字段: jsonrpc 定义 JSON-RPC API 的规范版本，method 是被调用的特定函数，params 是函数参数，id 用于对交易进行排序。传递给`eth_getBalance`的两个参数是需要检查余额的账户地址和需要查询的区块(此处 latest 用于检查最近挖出的区块中的余额)。
```s
curl -X POST http://127.0.0.1:8545 \
  -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0", "method":"eth_getBalance", "params":["0x915e89656d92368F7062d293984998FA5aaa0F3e","latest"], "id":1}'
```

成功调用将返回如下响应:
```json
  {"jsonrpc":"2.0","id":1,"result":"0x9ddc1e3b41d632fc8"}
```
余额位于返回的 JSON 对象的`result`字段中。但是，它以 Wei 为单位，并以十六进制字符串表示。将 0x9ddc1e3b41d632fc8 转换为十进制为 181999999978999882268，再除以 1e18 即是以太币余额 181.999999978999853。

### 检查账户列表

下面的 curl 命令返回所有帐户的列表。
```s
curl -X POST http://127.0.0.1:8545 \
    -H "Content-Type: application/json" \
   --data '{"jsonrpc":"2.0", "method":"eth_accounts","params":[], "id":1}'
```
或者使用`account_list`命令获取:
```s
  curl -X POST --data '{"id": 1, "jsonrpc": "2.0", "method": "account_list", "params": []}' http://localhost:8550 -H "Content-Type: application/json"
```

这都需要在 Clef 中批准。批准后，以下信息将返回到终端:
```json
  {"jsonrpc":"2.0","id":1,"result":["0x915e89656d92368f7062d293984998fa5aaa0f3e","0x29898201e9040f9ff41bd148ec3fc6d84e6a8829"]}
```

> 用户也可以通过打开新终端并运行`clef list-accounts --keystore <path-to-keystore>`直接从 Clef 列出帐户。

### 发送交易

账户间交易也可以使用 Curl 实现。注意，交易值是一个以 Wei 为单位的十六进制字符串。要转账 10 以太币，首先需要将其乘以 1e18 再转换为十六进制，将其转换为 Wei。10 以太币的十六进制表示为"0x8ac7230489e80000"。与之前一样，使用 Clef 密钥库中的地址更新 to 和 from 字段。
```s
curl -X POST http://127.0.0.1:8545 \
    -H "Content-Type: application/json" \
   --data '{"jsonrpc":"2.0", "method":"eth_sendTransaction", "params":[{"from": "0x915e89656d92368F7062d293984998FA5aaa0F3e","to": "0x29898201e9040F9ff41bD148ec3fC6d84E6A8829","value": "0x8ac7230489e80000"}], "id":1}'
```

在 Clef 中批准并输入发送方账户的密码确认后，Clef 将返回交易哈希，发出 Curl 请求的终端将显示包含交易哈希的响应。
```json
  {"jsonrpc":"2.0","id":1,"result":"0xc20a204db0285b16ddf4a6f05322bef104bb96a6dc3f32f4b31d50e5c9371910"}
```

### 创建账户

使用原始 JSON 请求也可以创建账户(本例使用 curl 将请求发送到 Clef 公开的 HTTP 端口):
```s
  curl -X POST --data '{"id": 0, "jsonrpc": "2.0", "method": "account_new", "params": []}' http://localhost:8550 -H "Content-Type: application/json"
```
执行后控制台将挂起等待 Clef 审批，Clef 终端批准并提示输入账户密码，然后在终端日志中确认账户创建。新的密钥文件将添加到`~/geth-ephemery/keystore`中的密钥库中。JSON 响应将返回到发起请求的终端，并在`result`字段中包含新的账户地址。
```s
  {"jsonrpc":"2.0","id":0,"result":"0x7ad12f1045fa3b7e23de94b37f491717ddf3c26a"}
```
