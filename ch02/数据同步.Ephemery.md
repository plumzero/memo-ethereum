参与对象: Geth + Lighthouse

同步耗时小于 5 分钟。

启动 Geth 端:
```s
  source ephemery/nodevars_env.txt
  cd ~
  geth --datadir geth-ephemery --syncmode snap --http --http.port 8545 --http.api eth,net --authrpc.addr localhost --authrpc.port 8551 --authrpc.vhosts localhost --authrpc.jwtsecret geth-ephemery/jwtsecret --bootnodes $BOOTNODE_ENODE --networkid $CHAIN_ID
```

启动 Lighthouse 端:
```s
  source ephemery/nodevars_env.txt
  cd ~
  lighthouse bn -t ephemery --execution-endpoint http://localhost:8551 --execution-jwt geth-ephemery/jwtsecret --boot-nodes=$BOOTNODE_ENR_LIST --checkpoint-sync-url https://checkpointz.bordel.wtf
```

> 如果本地之前同步过数据，但本地数据拉下 checkpoint 太多，可以通过`--purge-db`或`--purge-db-force`参数将本地数据删除，然后从 checkpoint 处同步。

更多日志可以查看[Geth同步日志](file/log.ephemery-sync-geth)和[Lighthouse同步日志](file/log.ephemery-sync-lighthouse)。

可以启动 JavaScript 控制台查看同步是否完成:
```s
  geth attach http://127.0.0.1:8545
```

笔者这里是:
```s
Welcome to the Geth JavaScript console!

 modules: eth:1.0 net:1.0 rpc:1.0

To exit, press ctrl-d or type exit
> eth.syncing
false
```
输出为 false，表示节点已经完成同步。

数据同步完成了，可以查看某些账户的信息，例如:
```s
> web3.fromWei(eth.getBalance('0xF19755Cb7919Af33B6A9cc903d4639F765DB505E'), 'ether');
9.749621967998676888
> web3.fromWei(eth.getBalance('0xc5742B62ab387fabe3472754680c19ba94250360'), 'ether');
0.25
```
