参与对象: Geth + Lighthouse

同步了 3~4 个小时后，状态数据(state)卡在了 97%，eth.syncing 输入不为 false，不知道是硬件原因还是其他原因。

启动 Geth 端:
```s
  cd ~
  geth --hoodi --datadir geth-hoodi --syncmode snap --http --http.port 8545 --http.api eth,net --authrpc.addr localhost --authrpc.port 8551 --authrpc.vhosts localhost --authrpc.jwtsecret geth-hoodi/jwtsecret
```

启动 Lighthouse 端:
```s
  cd ~
  lighthouse bn --network hoodi --execution-endpoint http://localhost:8551 --execution-jwt geth-hoodi/jwtsecret --http --checkpoint-sync-url https://hoodi-checkpoint-sync.stakely.io
```

更多日志可以查看[Geth同步日志](file/log.hoodi-sync-geth)和[Lighthouse同步日志](file/log.hoodi-sync-lighthouse)。

可以启动 JavaScript 控制台查看同步是否完成:
```s
  geth attach http://127.0.0.1:8545
```
