本节包含 Geth 基础主题的文档。这些页面将帮助您从用户角度理解 Geth 的工作原理及其底层机制。

在这里，您将找到有关如何管理 Geth 节点及其功能的信息。

例如，这些页面将帮助您了解 Geth 节点的底层架构、如何使用命令行选项以不同的配置启动它、如何同步区块链以及如何管理账户。此外，还有一个关于安全实践的页面，可以帮助您保护 Geth 节点免受攻击。

另请注意，还有一个页面解释了 Geth Discord 和 GitHub 上经常查询的常见日志消息——这将帮助用户解读控制台显示的消息并了解应采取的措施。

本节内容
- 节点架构: 了解以太坊节点的三个组件及其工作原理
- 命令行选项: 查看可用于配置 Geth 的各种命令行选项(内容略)
- 安全性: 了解 Geth 的基本安全最佳实践
- 同步模式: 了解 Geth 同步区块链的不同方式
- Beacon Light 同步: 了解 Beacon Light 客户端的集成模式和独立模式
- 账户管理: 了解如何使用 Clef 和 Geth 管理账户
- 数据存储: 了解数据存储的两个部分以及推荐的数据库
- 备份和恢复: 了解如何备份和恢复 Geth 实例的数据
- 日志: 了解如何解读 Geth 在控制台中显示的主要日志消息
- 连接到对等节点: 了解 Geth 的对等网络
- 修剪: 了解 Geth 的数据修剪选项
- 通过 Kurtosis 建立私有网络: 了解如何使用 Kurtosis 建立包含多个 Geth 节点的私有网络
- 配置文件: 了解如何使用配置文件来调整 Geth
- 挖矿: 了解在以太坊网络转向权益证明 (PoS) 之前，Geth 用于保护以太坊安全的挖矿算法
